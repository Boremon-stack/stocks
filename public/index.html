Volatility-managed portfolios · NSE

Hold less when the market is shaking. Measure whether it helps.

Volatility Lab implements the rule from Moreira and Muir's paper Volatility-Managed Portfolios (SSRN 2659431). It scales your exposure by recent realized variance, then tests the result on data the rule never saw.

Method

How the rule works

The maths follows the paper. You can reproduce any number on the page from the same CSV.

Measure the risk

Turn each day's close into a return, then average the squared returns over the last 20 days.

vt = mean(r²) over 20 days

Scale the exposure

Hold more when variance is low, less when it is high. The constant c is fixed on the first 70% of the data only.

wt+1 = c / vt

Test it honestly

Judge the rule on the last 30%, after costs for every change in exposure. Compare CAGR, Sharpe and drawdown with buy and hold.

Rt+1 = wt+1 rt+1 − cost·|Δw|

Daily mode

The 20-day rule from the workflow. Exposure is capped between 0% and 100%, so the strategy never borrows.

Paper mode

The paper's monthly version. It uses last month's realized variance, and the exposure is not capped, so it can exceed 100%.
